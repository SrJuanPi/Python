# Portafolio de Proyectos Python 🐍

Una colección de proyectos Python que demuestran fundamentos de programación, habilidades de resolución de problemas y desarrollo de aplicaciones del mundo real.

## 📁 Descripción General de Proyectos

### 🎂 Calculadora de Cumpleaños
**Archivo:** `birthday.py`
- Calcula la edad exacta (años, meses, días) a partir de la fecha de nacimiento
- Validación de fecha y manejo de fechas futuras
- Interfaz interactiva en consola

### 📅 Calculadora de Día del Año
**Archivo:** `date_of_year.py`
- Determina qué día del año es una fecha dada
- Maneja años bisiestos con precisión
- Muestra el porcentaje de progreso del año

### 🕹️ Simulador de Control Joystick
**Archivo:** `joystick.py`
- Simula entrada de joystick y detección de movimiento
- Mapeo de controles y análisis direccional
- Cálculo de distancia desde el centro

### 💰 Análisis de Rentabilidad
**Archivo:** `profitability.py`
- Análisis financiero de rentabilidad de proyectos
- Cálculos de ROI y período de recuperación
- Generación de reportes profesionales

### 🛒 Sistema de Carrito de Compras
**Archivo:** `shopping.py`
- Gestión completa del carrito con seguimiento de inventario
- Cálculo de descuentos e impuestos
- Generación de recibos con resumen detallado

### 📚 Sistema de Gestión de Biblioteca
**Directorio:** `Library/`
- Sistema integral de gestión de libros de biblioteca
- Agregar, buscar, prestar y devolver libros
- Persistencia de datos basada en JSON
- Seguimiento completo del inventario

**Archivos:**
- `library.py` - Lógica principal del sistema
- `books.json` - Base de datos de libros

### 🔐 Sistema de Login
**Directorio:** `Login/`
- Sistema de autenticación de usuarios
- Validación de credenciales
- Manejo seguro de contraseñas

**Archivos:**
- `login.py` - Módulo de autenticación

### 🎮 Solucionador de Laberintos
**Directorio:** `Maze/`
- Generación y resolución de laberintos usando algoritmo BFS
- Soporte para múltiples archivos de laberinto
- Visualización de ruta de solución
- Conteo de pasos

**Archivos:**
- `maze.py` - Motor de laberintos
- `maze.txt`, `maze1.txt`, `maze2.txt` - Laberintos de ejemplo

### ✅ Gestor de Lista de Tareas
**Directorio:** `todo_list/`
- Aplicación completa de gestión de tareas
- Priorización de tareas (baja, media, alta)
- Seguimiento de finalización con marcas de tiempo
- Persistencia en JSON

**Archivos:**
- `todo_list.py` - Aplicación principal
- `todo.json` - Almacenamiento de tareas
